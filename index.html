01

Blocks → notes

Solana produces a block every ~400ms. Each one plays a note, so the network's real speed is the tempo.

02

Validators → melodies

Each validator leads for 4 slots. Its address deterministically picks a scale position, timbre and 4-note motif, so it always plays its own phrase.

03

Transactions → rhythm

Live SPL token transactions tick as hi-hats. Failed ones snap as snares. Network TPS opens the filter on the bass pad.

04

Skipped → dissonance

When a validator misses its slot, the chain confirms the gap a few seconds later and you hear it as a dark, clashing thud.
